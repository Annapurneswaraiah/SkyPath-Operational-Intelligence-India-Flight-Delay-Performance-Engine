# Airport Operations SQL Project
## Project Name
Airport Operations Data Analysis
## Database
airline_delay_db
## Table
airline_uncleaned
## Description
This project analyzes airport operations data using MySQL. The dataset was cleaned, SQL views were created for KPIs, and window functions were used to perform advanced data analysis.
## SQL Files
### cleaning.sql
- Handles missing values
- Removes duplicate records
- Trims whitespace
- Standardizes data
### views.sql
- Airline Performance View
- Airport Performance View
- Weather Delay View
- Monthly Flights View
### window_functions.sql
- Running Total
- RANK()
- LAG()
- LEAD()
## Tools Used
- MySQL Workbench
- SQL
- Python (Pandas) for data cleaning

Airport_Operations_20k_Realistic.csv
